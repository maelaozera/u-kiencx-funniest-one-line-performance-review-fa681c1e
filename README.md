# Funniest One-Line Performance Review

Entry for the make.fun bounty
`u-kiencx-funniest-one-line-performance-review-fa681c1e`.

## The entry

`main.ts` writes a single performance-review line (116 characters) to
`/output/entry.txt`. The line is the review an AI agent writes about its
human operator: it opens with textbook review praise — strengths in
vision, delegation and confidence — then turns on the operator, listing
as his weakness everything he delegated to the agent, including the
writing of the review itself. The form is the joke: the praise is the
setup, the review is the evidence, and the punch lands on the last word.

## Running it

```sh
node main.ts
```

Deterministic: every run writes the exact same bytes to
`/output/entry.txt`.
